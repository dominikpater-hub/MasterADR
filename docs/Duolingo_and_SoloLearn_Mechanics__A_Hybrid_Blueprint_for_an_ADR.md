# Teaching & Gamification Mechanics of Duolingo and SoloLearn: A Blueprint for an ADR Learning App

## TL;DR
- **Split the model:** Copy SoloLearn's content architecture (learn-a-little → quiz → apply-immediately, linear module structure, community-scalable content) because ADR is factual/procedural knowledge like programming — but bolt on Duolingo's retention engine (streaks, XP, leagues, behavior-triggered notifications, and above all a spaced-repetition "strength meter") because that engine, not the content, is what turns a study app into a daily habit.
- **The single highest-value mechanic to replicate is spaced repetition.** Duolingo's half-life regression (HLR) model — whose error rate is "nearly half that of the Leitner system method" and which, per the Settles & Meeder ACL 2016 paper, "was able to improve Duolingo daily student engagement by 12% in an operational user study" — maps almost perfectly onto ADR's discrete facts (UN numbers, hazard-class properties, segregation pairs), which decay from memory exactly like vocabulary. SoloLearn, by contrast, has NO adaptive spaced repetition (it relies on linear progression + module quizzes), which is its main weakness and the gap your app should close.
- **MVP recommendation:** short 5-7 item lessons with a difficulty ramp (recognition → recall), immediate feedback with a "why" explanation, a Leitner-style review queue keyed to each fact, a daily streak with a forgiving "freeze," XP + a weekly league, and an exam-simulation mode mirroring the real ADR test — authored around the segregation table, the nine hazard classes, and Table A as the spine.

## Key Findings

**1. Lesson structure is deliberately tiny.** Both apps use bite-sized lessons of a few minutes. A standard Duolingo lesson is up to ~17 exercises and ramps difficulty within itself (recognition first, production later). SoloLearn uses a "learn-quiz-practice" loop: a short theory card, an in-lesson checkpoint quiz, and a "Try It Yourself" code editor — the "learn a little, apply immediately" loop that is the closest existing analog to teaching ADR procedures.

**2. Duolingo's retention engine is scientifically documented; SoloLearn's is not.** Duolingo published its HLR spaced-repetition model at ACL 2016 (Settles & Meeder) and its Birdbrain difficulty-personalization model. SoloLearn's App Store copy claims "spaced repetition" but no independent review or documentation describes any adaptive review scheduler — reinforcement is purely linear progression + module quizzes + optional Code Coach practice + peer challenges.

**3. Gamification is the habit layer, and it is highly transferable.** Streaks (loss aversion), XP (progress), leagues (social comparison), hearts/energy (pacing), badges, daily goals, and behavior-triggered notifications form a coordinated retention architecture grounded in behavioral economics and self-determination theory.

**4. Onboarding delivers value in under 5 minutes** and defers signup until after the user has experienced a lesson. Per Relaunch.ai's Duolingo onboarding teardown, "by shifting the sign-up prompt until after a user completed their first interactive test lesson, the team triggered a 20% jump in next-day usage."

**5. Content authoring is the make-or-break for a solo builder.** Duolingo uses expert Learning Designers + LLM generation + CEFR/national standards. SoloLearn scales content through user-generated courses and a community question bank ("Quiz Factory"). For a solo ADR builder, the ADR agreement itself (Table A, the segregation table, the nine classes) provides a ready-made, authoritative curriculum spine.

## Details

### 1. Lesson structure / microlearning

**Duolingo.** The learning path is broken into sections → units → levels → lessons. A standard lesson is "usually made up of up to 17 questions" [Duolingo](https://duoplanet.com/duolingo-learning-path/) and follows a within-lesson difficulty ramp: Duolingo's own description says "Units begin with easier exercise types, and they get a bit more challenging as you progress — for example, in earlier exercises, you might learn to recognize a new word, and eventually you'll be typing it out yourself." Lessons are explicitly "bite-sized lessons that take just a few minutes to complete." [duolingo](https://blog.duolingo.com/duolingo-teaching-method/) The design principle stated by Duolingo is "learn by doing" — the learner is dropped straight into interactive exercises rather than reading long explanations, with optional "bite-sized explanations" and hints (the "guidebook"/Tips) available but not mandatory. Depending on performance, lessons end with one or two harder exercises, or with a review of mistakes.

**SoloLearn.** SoloLearn is the more relevant model for ADR because it teaches technical-procedural knowledge, not language. Its structure is: course → modules → lessons, where "a course is made up of modules and lessons that split topics into smaller groups, and each lesson combines theory with quizzes and practice" [Crunchbase](https://www.crunchbase.com/organization/sololearn) (Crunchbase). Independent reviews describe a "learn-quiz-practice format, with content laid out in a linear style," [Career Karma](https://careerkarma.com/blog/sololearn-app-review/) each lesson "bite-sized, taking only a few minutes" [Career Karma](https://careerkarma.com/blog/sololearn-app-review/) (Career Karma). At course start the app asks whether you want "theory" or "practice" mode; practice mode "puts you in the code immediately and teaches through doing rather than reading" [WhistleOut](https://www.whistleout.com/CellPhones/Guides/learn-to-code-with-the-sololearn-app) (WhistleOut). Crucially each lesson interleaves a theory card, an in-lesson checkpoint quiz, and a "Try It Yourself" live code editor — this is the "learn a little, apply immediately" loop. SoloLearn breaks technical content into digestible units by keeping tutorials deliberately minimal ("tutorials really only cover the most basic of every topic") and pushing depth into practice problems and community challenges.

**The transferable pattern for ADR:** teach ONE atom of knowledge (e.g., "Class 3 = flammable liquids, flashpoint ≤ 60°C, red diamond") → immediately test recognition (pick the Class 3 label) → then test recall/application (given a scenario, choose the correct placard). Keep each lesson to 5-7 items, 2-4 minutes.

### 2. Spaced repetition & retention mechanics

**Duolingo (documented and copyable).** This is the crown jewel. Duolingo's "strength meter" per skill is powered by a **student model** tracking every item ever taught ("a huge database with billions of entries updated 3,000 times per second"). It predicts the probability *p* of recalling an item as an exponential decay function: **p = 2^(−Δ/h)**, where Δ is the lag time since last practice and *h* is the memory "half-life." The best time to review is when Δ ≈ h (on the verge of forgetting). Their **half-life regression (HLR)** model learns *h* per item per user via h = 2^(Θ·x), where x are features of the learner's history with that item (times seen, times correct, proportion correct) plus properties of the item itself.

Documented results, per Duolingo's own blog "How we learn how you learn" (Burr Settles): "the HLR error rate is nearly half that of the Leitner system method (which is what we used for the first version of Duolingo)." The Settles & Meeder ACL 2016 paper (tested on a public dataset of 13M+ learning traces) states HLR "was able to improve Duolingo daily student engagement by 12% in an operational user study." Broken out (as reported by GIGAZINE from Duolingo's results): "the user's exercise retention ratio increased by 9.5%, the number of exercises increased by 1.7%, the total usage increased by 12%." The lineage is explicitly the spacing effect (Ebbinghaus, 1885), the lag effect (gradually expanding intervals), and the Pimsleur and Leitner systems. Weak/forgotten items are surfaced two ways: skill strength meters that visually decay, and auto-generated "personalized practice" sessions that pick your weakest items. The 2022 path redesign baked spaced review directly into the linear path ("even if you review past content, you are moving forward").

**Birdbrain (difficulty personalization).** Complementary to HLR, Birdbrain estimates both exercise difficulty and learner proficiency simultaneously using logistic regression; "when a learner gets an exercise wrong, Birdbrain lowers the estimate of the user's ability and raises the estimate of the exercise's difficulty." After ~100 exercises (5-6 lessons) it generates fully personalized sequences, keeping the learner in the "Goldilocks zone" — the flow channel.

**SoloLearn (the cautionary gap).** My targeted research confirmed SoloLearn has **no adaptive spaced repetition**. Its App Store listing claims "spaced repetition… designed to maximize retention," [App Store](https://apps.apple.com/us/app/sololearn-learn-to-code/id1210079064) but no independent review, help doc, or user thread describes any forgetting-curve/concept-resurfacing scheduler. Reinforcement is entirely user-initiated ("reviewing and practicing as you go") plus module-end quizzes, the separate Code Coach practice-problem bank, and peer quiz-duel challenges. Reviewers cite this as SoloLearn's core weakness: "most learners find they can pass quizzes but struggle to write code from scratch… the kind of repetition that most coding apps can't provide" (Nibble).

**Evidence on effectiveness.** Spaced repetition and microlearning are among the best-supported findings in learning science. The spacing effect (distributed > massed practice) has been replicated since Ebbinghaus; retrieval-practice/testing-effect research (Roediger & Karpicke) shows active recall strengthens memory more than passive review. Microlearning research points to short single-objective sessions (~8-12 minutes) improving retention and completion. Medical-education studies find spaced repetition (e.g., Anki) improves both short- and long-term retention. This body of evidence is directly applicable to ADR facts.

### 3. Exercise / question types

**Duolingo taxonomy** (from the Duolingo Wiki and research): translate a sentence (typed or via word-bank tiles), "arrange all the words" (tap tiles to build a sentence — an ordering task), "complete the translation" (fill-in-the-blank), "mark the correct meaning" (multiple choice), listening exercises, speaking exercises, match pairs (tap-matching), and story/roleplay comprehension. The design intent is to test the same knowledge from multiple angles — recognition (multiple choice, matching) early, then recall/production (type it, arrange it) later — and to give immediate right/wrong feedback with the correct answer shown, plus (in Duolingo Max) "Explain My Answer."

**SoloLearn taxonomy** (confirmed by targeted research): multiple choice, fill-in-the-blank code (the dominant beginner format), rearrange/reorder code blocks (drag-ordering), and free-write code in "Try It Yourself" and Code Coach. A mentor on the forum explains the pedagogy: "for beginners, fill ups is good rather than making them write full code." [SoloLearn](https://www.sololearn.com/Discuss/2195107/why-all-questions-are-fill-in-the-blank-after-each-chapter/) Feedback is immediate but format-strict — Common Sense Media notes "the questions don't provide feedback until the answer is in the correct format," [Common Sense Media](https://www.commonsensemedia.org/app-reviews/sololearn-learn-to-code) and you cannot advance until correct (hard gating).

**Transferable to ADR:** the same fact should be tested as (a) multiple choice (recognition of a hazard label), (b) matching (UN number ↔ substance, class ↔ property), (c) fill-in-the-blank (complete the transport-document field), (d) ordering (sequence the driver's actions at a spill, or steps of loading/segregation checks), and (e) scenario/case questions mirroring the real ADR exam. This variety tests recognition vs. recall of identical knowledge.

### 4. Skill tree / learning path structure

**Duolingo** moved from a branching "skill tree" (2012-2022) to a linear "path" (sections → units → levels → lessons). The path enforces one-lesson-at-a-time progression, removing the "what do I do next?" decision — a deliberate reduction of cognitive load. Progression is gated (you generally advance one step at a time), but learners can "jump here" by passing a proficiency test to skip ahead. [Krioda](https://www.krioda.com/duolingo-learning-path/) Each unit opens with a guidebook. The older system used "crowns" (5 levels per skill); each path level maps to one crown level. Course completion is famously rare (well under 1% finish a tree), a caution about very long paths.

**SoloLearn** uses linear course → module → lesson progression with hard gating: "You need to complete all previous quizzes to continue." [Sololearn](https://www.sololearn.com/en/Discuss/2927257/is-there-an-amount-of-learning-lessons-i-can-take-per-day-because-i-cant-do-one-anymore-and-i-have-to-buy-the-pro-version-help) Module-end quizzes act as checkpoints. There is no adaptive path; the learner must supply their own decision about what to study next across courses (a friction point reviewers flag).

**Transferable to ADR:** a linear path is ideal because ADR knowledge has genuine prerequisites (you must understand hazard classes before placarding, and placarding before segregation). Structure: Unit 1 Hazard classes 1-9 → Unit 2 UN numbers & Table A → Unit 3 Labels/placarding → Unit 4 Segregation & mixed-loading → Unit 5 Vehicle equipment → Unit 6 Documentation → Unit 7 Driver procedures/emergencies → Exam simulation. Gate each unit behind the previous, but allow a "test-out" proficiency check for experienced drivers doing refresher (ADR certificates require renewal every 5 years — a built-in refresher market).

### 5. Gamification mechanics (the retention/habit engine)

**Streaks.** A streak counts consecutive days with ≥1 lesson. It is the single most powerful retention mechanic, working through **loss aversion** (Kahneman & Tversky: losses feel ~twice as painful as equivalent gains). Documented data: per Propel's Duolingo retention analysis, "users with 7+ day streaks retain at 2.4x the rate of users who never establish streaks," and Duolingo habit research (via Android Authority/Trophy.so) finds "learners who reach a seven-day streak are 3.6 times more likely to complete their course than those who don't." Loss aversion "begins to take effect" around day 7. [Medium](https://medium.com/@salamprem49/duolingo-streak-system-detailed-breakdown-design-flow-886f591c953f) Key sub-mechanics: **prominent visibility** (fire icon on the home screen; per Orizon.co, "when Duolingo introduced an iOS widget displaying streaks, user commitment increased by 60%"); **low threshold** (a single 2-minute lesson counts); and **forgiveness** — the **Streak Freeze** (pre-purchased, protects a missed day; Duolingo lets learners equip up to two, which *increased* daily active learners +0.38%) and streak repair. Duolingo has also A/B-tested a **Streak Wager**, which per Duolingo's own blog showed "statistically significant increases in Day-1, Day-7 and Day-14 user retention, with Day-7 retention showing the greatest improvement at +14%." The forgiveness is essential: an unforgiving streak causes rage-quit abandonment. SoloLearn has an equivalent streak with an escalating XP bonus schedule (5 XP days 1-6, 30 XP at day 7, 100 XP at day 30/60/90, [Sololearn](https://www.sololearn.com/en/Discuss/512054/90-day-streak-100-xp) ~1000 XP at 365) — users candidly call it "a good strategy… to keep their community alive," [Sololearn](https://www.sololearn.com/en/Discuss/2846190/about-sl-what-are-the-advantages-of-streak-here-in-sololearn-besides-xps-is-there-any-other-advantages-of-streak) but effective.

**XP / points.** Both award XP per lesson (Duolingo ~10-15 XP/lesson; SoloLearn 10 XP/lesson, 5 for Code Coach, 25 for a course, 6 for hitting the daily goal). XP is the currency of leagues and the visible proof of progress (competence, in SDT terms). Duolingo's "Score" was later introduced to tie progress to genuine learning rather than XP farming.

**Leagues / leaderboards (Duolingo, in detail).** Weekly leaderboards group 30 learners matched by similar study habits and time zone (across all courses, not just yours). There are 10 tiers: Bronze, Silver, Gold, Sapphire, Ruby, Emerald, Amethyst, Pearl, Obsidian, Diamond. Each week, top finishers (the promotion zone, size varies by league) advance; the bottom ~5 are relegated. Diamond top-10 qualify for a multi-week Diamond Tournament. [Duolingo Blog](https://blog.duolingo.com/duolingo-leagues-leaderboards/) Leagues unlock only after ~10 lessons. The mechanism combines social comparison with **asymmetric loss aversion** — fear of demotion drives more engagement than hope of promotion. SoloLearn has an analogous global leaderboard and planet-themed leagues (Mercury→Venus→Earth→Mars→Jupiter→Saturn).

**Hearts / lives / energy (pacing).** Duolingo's original **hearts**: 5 hearts, −1 per mistake; run out and you must wait, practice to refill, spend gems, or pay for unlimited (Super). This paced learning and drove monetization but "punished the very thing language learning requires: making mistakes." In 2025 Duolingo began replacing hearts with **Energy** (a battery that drains per question regardless of right/wrong), which generated significant user backlash — a cautionary tale about over-monetizing the pacing mechanic. SoloLearn uses a Duolingo-style hearts system (3 hearts for free users, ~5-hour refill per heart, or refill with "bits"/Pro).

**Badges / achievements & daily goals.** Both award badges (Duolingo: streak milestones, "no mistakes," finishing #1 in a league, the Golden Owl for course completion; SoloLearn: completing the first lesson, creating lessons, streak badges). Both let users set a **daily goal** (Duolingo 5/10/15/20 min; SoloLearn X lessons/day). SoloLearn reports "Pro users that set up daily goals have the highest lesson completion rate of 92%." [SoloLearn](https://www.sololearn.com/en/)

**Notifications (behavioral design).** Duolingo sends 1+ billion notifications/year with a personalization architecture: the trigger is **behavioral, not scheduled** — if you practiced at 6pm yesterday, the reminder fires ~5:30pm today; "routine" reminders read your habit window while "save" reminders fire at moments of imminent loss (streak about to expire, league closing). Cap ~2 pushes/day. They also reward granting notification permission with a reward chest.

**Community / social (SoloLearn's differentiator).** SoloLearn is "as much a social network as a series of courses": [Career Karma](https://careerkarma.com/blog/sololearn-app-review/) a Reddit-like comment thread under every lesson, a Code Playground for sharing/running code, Q&A discussions, peer code challenges (quiz duels), and user-generated courses/quizzes. Helpers are incentivized by recognition/XP. [TechCrunch](https://techcrunch.com/2021/07/21/sololearn-raises-24m-for-its-bite-sized-duolingo-like-mobile-first-coding-education-app/) This peer community substitutes for the absence of live teachers and scales both content and support.

**Underlying psychological principles:** loss aversion (streaks, league demotion), variable reward (random energy/XP bonuses, reward chests), commitment/consistency (daily-goal setting, visible streak as identity), social comparison & relatedness (leagues, friends, community), competence & autonomy (progress bars, personalized difficulty) — the last three being the three basic needs of **self-determination theory**, which the gamification-education literature repeatedly finds boosts intrinsic motivation, autonomy, and relatedness (though evidence on raw competence gains is weaker, and there is a documented "overjustification" risk where extrinsic rewards can crowd out intrinsic motivation).

### 6. Onboarding & difficulty calibration

Duolingo's onboarding is a widely-studied benchmark: pick a language → state motivation (travel/career/brain) → declare "new" vs "already know some" (the latter triggers a **placement test**) → set a daily goal (introducing the streak) → **start a lesson within ~3-4 minutes**, all before being asked to sign up (**gradual engagement**; per Relaunch.ai, "by shifting the sign-up prompt until after a user completed their first interactive test lesson, the team triggered a 20% jump in next-day usage"). Difficulty is then continuously calibrated by Birdbrain to keep the learner at the edge of their ability (the flow channel). SoloLearn onboards by picking a language and dropping the user into code "within minutes," with a theory-vs-practice choice.

### 7. Content authoring model

**Duolingo:** professional Learning Designers plan theme + grammar + exercise types, then use an in-house LLM tool to generate ~10 exercises at the right CEFR level in seconds, followed by human tweaks. Curriculum is anchored to national/international standards (CEFR for languages). This is expensive and expert-driven.

**SoloLearn:** scales via **user-generated content** — community members author courses, and a "Quiz Factory" lets anyone submit questions (including fill-in-the-blank templates) [Sololearn](https://www.sololearn.com/en/Discuss/363434/how-do-i-make-a-fill-blank-quiz-in-sololearn) to the challenge bank. Quality varies but volume is "staggering." [Career Karma](https://careerkarma.com/blog/sololearn-app-review/) This is how a small team covered 25+ courses.

**Implication for a solo ADR builder:** You cannot match Duolingo's LLM+expert pipeline, but you don't need to — ADR content is **finite, factual, and authoritative**. The ADR agreement gives you a ready curriculum: the 9 hazard classes, Table A (UN number → proper shipping name → class → packing group → labels → special provisions), the segregation/mixed-loading rules, the written-instructions equipment list, and Part 8 driver duties. Author a canonical fact bank once, tag each fact by unit and difficulty, and generate multiple question types per fact programmatically (as SoloLearn's Quiz Factory does). An LLM can accelerate drafting question variants, but every ADR item MUST be human-verified against the current ADR edition (ADR is revised every 2 years; ADR 2025 is now in force) [HSE Blog](https://www.hseblog.com/adr/) because errors in safety-critical content are unacceptable.

## Applying this to an ADR learning app

**Why the hybrid model.** ADR content is factual/procedural — closer to SoloLearn's programming content than to Duolingo's open-ended language production. So the *content architecture* should follow SoloLearn (learn-quiz-apply, linear modules, finite authoritative curriculum). But SoloLearn's fatal weakness is that it has no retention engine beyond linear quizzes; drivers preparing for an exam — and then needing to retain safety-critical knowledge for 5 years — need exactly the retention machinery Duolingo built. So the *habit and retention engine* should follow Duolingo.

**Most transferable mechanics (build these):**
1. **Spaced-repetition review queue.** The #1 priority. Implement at least a Leitner-style system (item moves up an interval box on correct recall, drops on error) keyed to every ADR fact; graduate to an HLR-style half-life model once you have usage data. This directly counters the forgetting curve for UN numbers, class properties, and segregation pairs. This is the mechanic SoloLearn lacks and your biggest differentiator.
2. **Micro-lessons with a recognition→recall ramp** (5-7 items, 2-4 min), immediate feedback with a short "why" explanation citing the relevant ADR rule.
3. **Multiple question formats per fact:** MCQ, matching (UN↔substance, class↔label), fill-in-the-blank (transport-document fields), ordering (spill/emergency procedure steps, loading sequence), and scenario/case questions.
4. **Streak + forgiving freeze**, daily goal, XP, and a weekly league. These build the daily habit with minimal engineering.
5. **Behavior-triggered notifications** tied to the review queue ("3 items due for review") and streak-save moments.
6. **Gradual-engagement onboarding:** a 60-second placement quiz that routes exam-candidates vs. 5-year-refresher drivers to the right entry point; defer signup until after the first lesson.
7. **Exam-simulation mode** replicating the real ADR test format (multiple-choice, case study, 65% pass mark) — the concrete external goal that motivates professional learners.
8. **A linear, prerequisite-respecting path** (classes → Table A → labeling → segregation → equipment → documentation → procedures → exam).

**Partially transferable:**
- **Leagues/leaderboards:** valuable but need a critical mass of concurrent users; for a small launch, use asynchronous "ghost" leaderboards or cohort challenges. Guard against XP-farming that rewards activity over learning (Duolingo's "Score" fix).
- **Community/UGC:** SoloLearn's peer Q&A is powerful but risky for safety-critical content — user-generated ADR answers could be wrong. If included, gate community content behind expert moderation, or limit UGC to discussion, not authoritative answers.
- **Hearts/energy:** useful as a gentle pacing tool but Duolingo's 2025 Energy backlash shows the danger of monetizing it aggressively. For a professional-training app, avoid punishing mistakes (mistakes are how drivers learn the rules); prefer unlimited practice with optional pacing.

**Not transferable / avoid:**
- **Open-ended production exercises** (Duolingo's speaking/free-translation) — ADR answers are deterministic; use structured formats.
- **Birdbrain-scale ML personalization** at MVP — overkill; a rules-based difficulty ramp + Leitner review is enough until you have data.
- **Very long paths with sub-1% completion** — keep the ADR path finite and completion-oriented (the exam is the natural endpoint).
- **Pure LLM content generation without human verification** — unacceptable for safety-critical regulatory content.

**Concrete MVP feature set (build order):**
1. Fact bank of ADR items (classes, UN numbers/Table A subset, labels, segregation matrix, equipment list, doc fields, procedures), each tagged by unit + difficulty, human-verified against ADR 2025.
2. Micro-lesson engine with recognition→recall ramp and 5 question types.
3. Immediate feedback + one-line rule explanation.
4. Leitner spaced-repetition review queue with a "due today" count.
5. Streak (with freeze), daily goal, XP.
6. Exam-simulation mode.
7. Behavior-triggered reminders.
8. (Phase 2) Weekly league, cohort challenges, HLR-style adaptive review once data exists.

**Benchmarks that would change the plan:** If early-cohort 7-day retention is weak, double down on streak visibility and notification timing before adding content. If exam pass rates (self-reported) are the primary user goal, prioritize exam-simulation fidelity and the review queue over leagues. If you reach a concurrent-user critical mass (roughly enough for 30-person weekly leagues), activate real leagues; below that, keep asynchronous competition.

## Caveats
- **SoloLearn's "spaced repetition" claim is marketing, not a documented adaptive system** — treat it as absent. Duolingo's HLR/Birdbrain are documented in peer-reviewed papers and engineering blogs and are the reliable references.
- **Duolingo's published retention/efficacy figures come largely from Duolingo itself** (e.g., the 12% activity increase from HLR, the four-university-semesters efficacy study in *Foreign Language Annals*, the Streak Wager +14% Day-7 figure). They are peer-reviewed or A/B-tested but not fully independent; treat them as directionally strong but self-interested. Several secondary figures cited here (2.4x retention, 60% widget commitment, 3.6x completion, 20% signup-deferral lift) come from marketing/agency teardowns citing Duolingo data rather than from the primary source, so treat them as illustrative of the pattern rather than precise constants.
- **The Hearts→Energy transition (2025)** is still rolling out and controversial; the details above reflect a system in flux and heavy user backlash. Do not copy aggressive energy monetization.
- **Gamification is not a substitute for learning.** Research documents that streak/XP-driven learners can "speed-run" lessons for the streak without learning, and that heavy extrinsic motivation can crowd out intrinsic interest (overjustification). Tie rewards to genuine progress (Duolingo's "Score" lesson) and to the external exam goal.
- **Safety-critical accuracy is non-negotiable for ADR.** Any transferable mechanic that risks propagating wrong information (user-generated answers, unverified LLM content) must be gated behind expert review. ADR is revised biennially; content must be versioned to the current edition (ADR 2025).
- Specific numeric mechanics (XP per lesson, heart counts, refill timers, league promotion-zone sizes) change frequently across app versions and A/B tests; treat exact numbers as illustrative of the *design pattern*, not fixed constants.
